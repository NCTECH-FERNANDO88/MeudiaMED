# MeudiaMED
O MeudiaMED nasceu de uma necessidade real: conciliar a rotina intensa da área da saúde com os estudos contínuos. Médicos, residentes e estudantes precisam acompanhar horas de estudo, organizar plantões e controlar ganhos, tudo isso enquanto equilibram trabalho, descanso e vida pessoal o app centraliza essa gestão em uma única ferramenta.
